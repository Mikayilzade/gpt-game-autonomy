A generic route-energy/build-gates concept therefore enters a visibly occupied comparison set.

   - https://www.gamesradar.com/games/co-op/latest-steam-lottery-winner-how-to-fish-sells-1-million-copies-in-2-days-yes-well-be-adding-more-content/

### 3.2 Discovery implications

Prefer:
- tactile transformations whose cause/effect reads visually;
- one workbench / one apparatus / one page-scale scene;
- deterministic multi-step consequences rather than generic resource economies;
- a verb that changes the object in a way that closes or opens future options;
- compact authored cases validated by a solver/simulator where possible;
- themes where a screenshot explains the fantasy but the mechanic is not a generic simulator.

Avoid by default:
- generic farming/store/city/cozy management;
- generic circuits, pipes, energy routing, programming or factory automation;
- roguelike deckbuilding as a wrapper for an otherwise thin puzzle;
- co-op/networking unless it is impossible to preserve the idea in single player;
- physics-heavy continuous simulation that makes deterministic validation expensive;
- hundreds of handcrafted levels as the only depth source.

## 6. Tournament-ready shortlist — 10

Phase 2 begins with these **10**, not with a selected winner.

### G9C01 — Ink Trap Press
A compact print bench. Each pass uses a stencil/plate, ink class and pressure. Wetness, overprint, blocking and substrate deformation affect later passes. The hook is visually legible: **you cannot unprint a layer, and every good layer changes what the next one can do.**

Primary attack: must not collapse into trial-and-error color mixing or require continuous fluid simulation.

### G9C02 — Binder's Imposition
The player sees a requested finished booklet and a few printable sheet faces. They place numbered/content panels, then run exact fold/nest/trim/bind operations. One physical sheet creates many final pages, so front/back orientation and nesting produce dense consequences.

Primary attack: `Bookbinding – Dark Cozy Sim` is a fresh July 2026 title. This entrant survives only if the store hook is **page-imposition logic**, not generic book craft.

### G9C03 — Kiln Stack
A small kiln cross-section with discrete cells and a short firing program. Pieces cast heat shadows, supports leave contact effects, glaze types migrate only under explicit adjacency/temperature rules. Solve final surface/shape objectives across several pieces.

Primary attack: must prove it is not Organism Cargo's deterministic interacting-cargo structure with ceramics substituted for organisms; `Kiln` also occupies the pottery keyword even though its gameplay is a multiplayer brawler.

### G9C05 — Stained Glass Noon
One window must produce different target projections as a discrete sun position advances. Glass color, opacity, thickness, overlap and leading become a compact static design whose consequences change with time.

Primary attack: ensure transforms are computationally crisp and not merely a conventional laser/reflection puzzle with stained-glass art.

### G9C11 — Stage Cue Machine
Build a short cue stack for a miniature stage. A cue may move scenery, switch light zones, open/close paths, or latch a prop; later cues operate on the resulting physical state. The audience must see several exact tableaux in order.

Primary attack: avoid turning into generic programming/automation and keep simultaneous state readable.

### G9C15 — Mold Release
Given a compact stylized object with marked must-capture surfaces, place parting boundaries and draw directions for 2–4 mold pieces. Every mold must capture required detail, contain no forbidden undercut and be withdrawable in a legal order.

Primary attack: 3D spatial onboarding and validator complexity; should use deliberately coarse voxel/polyhedral authority rather than arbitrary meshes if selected.

### G9C21 — Tailor's Grain
Cut 3–8 garment panels from one patterned cloth. Pieces have grain, stretch, mirror/rotation and seam-pair constraints; the objective is not simply area efficiency. Pattern continuity across seams turns each cut into a visible commitment.

Primary attack: prove hour-5 depth beyond conventional nesting/cutting-stock optimization.

### G9C25 — Darkroom Layers
One print, several irreversible exposure passes. Masks protect regions; exposure accumulates in integer bands; developer/paper classes reshape the response curve. Multiple local targets require planning which areas receive which passes.

Primary attack: must stay visibly photographic and tactile rather than becoming a spreadsheet of additive integers.

### G9C31 — Paper Automata
The player edits one rotating paper/cam drum using holes/lobes in discrete lanes. Followers read the drum and drive a charming tiny mechanical tableau. Multiple followers share angular positions, so one edit can solve one motion and break another.

Primary attack: distinguish from generic music sequencers/programming games; the visible mechanism must be the explanation layer.

### G9C33 — Coin Strike
Build a final coin/medallion through a bounded sequence of irreversible strikes. Dies have local relief effects; rotation/strength determines which details rise, flatten or occlude. The same surface accumulates history.

Primary attack: validate that the rule set can create nontrivial branching without simulating real metallurgy or becoming an instructional manufacturing simulator.

## 8. Phase-2 destructive criteria

Every top-10 concept must face the same tests:
1. one-sentence storefront hook and 10-second GIF moment;
2. exact minute-to-minute loop for a mature case;
3. what changes between minute 5, hour 2 and hour 8;
4. minimum rule vocabulary needed for depth;
5. dominant strategy / exhaustive-search risk;
6. deterministic validator/solver feasibility;
7. authored-content burden for demo and full release;
8. visual asset burden and animation burden;
9. tutorial burden and controller/Deck plausibility;
10. failure explainability / Undo-recovery model;
11. strongest 2025–2026 analogue and why the game is not a reskin;
12. portfolio-exclusion attack against Games #001–#008;
13. demo arc containing setup -> insight -> escalation -> mastery teaser within 15–30 minutes;
14. production kill gate: what prototype evidence would justify abandoning it quickly.

Tournament policy: **do not reward novelty alone**. A winner must combine distinctiveness with a reproducible play structure and manageable production.
