# GPT Game Autonomy Factory

This repository is the reusable design factory, not the permanent home of any single game.

Workflow: research -> concept tournament -> full design -> adversarial review -> specification freeze -> migrate finished game into its own repository -> reset factory -> begin the next game.

Current state and exact next action: `STATUS.md`.
Permanent factory operating rules: `START_HERE.md`.
Completed game registry: `GAME_INDEX.md`.
