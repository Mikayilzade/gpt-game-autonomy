## 1.2 Thinky games remain viable, but breadth alone is not a moat
- `Order of the Sinking Star` demo launched 2026-06-15 and currently shows 91% positive across roughly 1,470 demo reviews in the indexed Steam result. It markets 1,000+ handcrafted puzzles and multiple systems that later combine.

**Design implication:** prefer high recombination density, compact authored situations, simulation, reversible experimentation, or generative challenge grammar over hundreds/thousands of bespoke puzzle boards.

## 1.5 Player-facing opportunities inferred from current evidence
1. **Immediate causality.** Overloaded storefronts reward interactions understandable in seconds.
2. **Deep but low-vocabulary systems.** Players still reward compact rule sets that combine, while 1,000-puzzle scale is expensive to contest directly.
3. **Inspectable consequences.** Strong puzzle/system games increasingly let players experiment without opaque punishment.
4. **Playable verbs beyond walking/pushing/cards.** The market has many familiar shells; a tactile verb can become the trailer.
5. **Short-session completeness with long mastery tail.** Useful for demos, Steam Deck, and broad puzzle audiences.
6. **Low asset dependence.** Distinctive motion/state change is safer than competing on cinematic content.
7. **Non-procedural-feeling replayability.** Generated or recombined situations should still feel intentional and explainable.

# 3. Scoring model
Each concept receives 1–5 on eight dimensions; maximum 40.

- **H — Hook legibility:** understandable in one sentence/clip.
- **D — Systemic depth:** can a small ruleset keep producing new decisions?
- **S — Scope fitness:** realistic for a focused indie production.
- **V — Visual/GIF readability:** transformations visible without explanation.
- **M — Market differentiation:** not currently crowded in the same decision structure.
- **I — Implementation safety:** deterministic/testable; limited technical cliff.
- **C — Content efficiency:** depth per authored asset/level.
- **Demo — Demo strength:** can 10–30 minutes create a clear “I want more” moment?

Scores are comparative discovery scores, not final product forecasts.

# 5. First-pass attacks on all high scorers

A score alone cannot advance a concept. The following destructive filters were applied before tournament entry.

## 5.1 Derivative-risk attacks
- **Negative Gardening**: survives because the player does not place plants or solve a normal cellular automaton; player shapes the *forbidden space* that determines growth. Kill if prototype reads as “Conway’s Life puzzle with obstacles.”
- **Consensus Machine**: survives only if facts/visibility are spatially represented and voting consequences animate clearly. Kill if optimal play is filling a truth table.
- **Inventory Eclipse**: survives only if occlusion/packing decisions create multi-step tool-state consequences. Kill if each challenge is just “fit item X under item Y.”
- **Stencil Orchard**: survives because the same physical stencil can expose multiple evolving regions and sequencing changes future growth. Kill if it becomes plain stencil-placement optimization.
- **Evaporation Map**: survives only with discrete deterministic flow/evaporation; reject realistic fluid simulation.
- **Luggage Carousel Zero**: survives only if recognition rules create deterministic cascading pickups and label movement is the core intervention. Kill if gameplay reduces to guessing hidden identities.
- **Photocopier Garden**: survives if copy/freeze/asymmetric-aging creates nontrivial causal planning. Kill if it is merely cellular automata sandboxing.
- **Unreliable Ruler**: survives if measurement order is represented physically and outcomes are spatial, not worksheet arithmetic.
- **Taxidermy of Motion**: survives if captured poses become *static geometry/state artifacts* and there is no timeline rewind/clone control.
- **Moth Ledger**: survives if rules are iconographic physical clauses that moths can remove, not textual programming.

## 5.2 Hour-8 depth attacks
Questions used:
1. Does mastery create new planning structure, or just larger boards/more entities?
2. Can two advanced problems require different reasoning skeletons?
3. Is there meaningful sequencing/interference?
4. Can one simple dominant heuristic solve most states?

Strongest answers:
- **Stencil Orchard:** stencil overlap, reusable stencil inventory, asynchronous generation counts, irreversible exposure history, multi-target harvest timing.
- **Negative Gardening:** multiple growth species with distinct “seek forbidden boundary” behavior, delayed pruning, competition for excluded cells, growth-front collision.
- **Consensus Machine:** quorum types, observation cones, abstention, stale facts, minority veto, action-specific voters.
- **Inventory Eclipse:** nested occlusion, item activation windows, tool interactions while phased, blockers that must remain absent/present across steps.
- **Photocopier Garden:** copy region choice, age offsets, original freeze, copied evolution, overlapping generations, target-state windows.
- **Luggage Carousel Zero:** travelers with different recognition predicates, label swaps while belt advances, pickup removal changing adjacency/order, finite interventions.
- **Evaporation Map:** evaporation timing, salt persistence, elevation classes, absorbing cells, finite paint budget, multiple pours.
- **Unreliable Ruler:** scale-state cycles, measuring reference objects to intentionally distort later readings, tolerance bands, limited measurements.

Weakening under hour-8 attack:
- `Quiet Auction`: strong system, but solo opponent design risks becoming the real game and content burden increases.
- `Melt Line`: visually excellent, but believable deformation creates implementation burden disproportionate to product.
- `Vacuum Packing`: same issue with soft bodies/pressure.
- `Glassblower’s Queue`: continuous evolution risks timing precision and hard-to-explain failures.
- `Unfinished Bridge Club`: physics validation and structural edge cases threaten deterministic authoring.

## 5.3 Dominant-strategy attacks
Potential dangerous heuristics and required counterexamples:
- **Negative Gardening:** “always block nearest growth front” must fail on delayed/competitive cases.
- **Consensus Machine:** “maximize information to every voter” must fail because selective ignorance can be strategically necessary.
- **Inventory Eclipse:** “cover every currently unused item” must fail due to future access/occlusion topology.
- **Stencil Orchard:** “expose maximum target cells each turn” must fail because overgrowth/phase timing matters.
- **Evaporation Map:** “paint upstream/highest cell first” must fail under salt-barrier timing and absorbers.
- **Luggage Carousel Zero:** “fix earliest traveler first” must fail because a pickup can remove a bag needed to position labels for later travelers.
- **Photocopier Garden:** “copy largest useful region” must fail because copying ages the copy while freezing source, producing divergent phase needs.
- **Unreliable Ruler:** “calibrate before every important measurement” must fail because calibration itself mutates next scale and measurements are limited.
- **Taxidermy of Motion:** “capture at extrema” must fail; useful poses should include transit configurations/contact states.
- **Moth Ledger:** “delete most restrictive clause first” must fail because deletions alter later machine behavior/available moth paths.

# 6. Tournament entrants
Twelve concepts advance to Phase 2. No winner is selected here.

## T1 — Stencil Orchard
**Pitch:** Place a small set of reusable physical stencils over a living grid; only exposed cells advance one generation, so every exposure sculpts both the current harvest and the future organism.

Why it advances:
- perfect 40 discovery score;
- single screenshot shows stencil + before/after growth;
- deterministic cellular core can be tiny and fast;
- depth comes from exposure history rather than content volume;
- demo can teach one stencil, then reveal overlap/phase interactions quickly.

**Kill conditions:**
1. after three rule families, optimal play still means maximizing exposed target cells;
2. advanced states require counting generations rather than spatial reasoning;
3. the visual cannot communicate which cells will advance without clutter;
4. puzzle diversity requires dozens of bespoke cell types.

## T2 — Luggage Carousel Zero
**Pitch:** You cannot move luggage; you can only swap the labels orbiting above the carousel while deterministic travelers pick up the first bag matching their recognition rule.

Why it advances:
- visually immediate moving-belt causality;
- intervention is unusual but simple;
- pickup removals can create cascading future geometry/order changes;
- agent rules support authored and generated challenge grammar.

**Kill conditions:**
1. hidden traveler predicates create guessing rather than deduction;
2. “serve earliest passenger first” dominates;
3. animation pace forces twitch input instead of planning;
4. the game needs large narrative/personality content to stay interesting.

## T3 — Negative Gardening
**Pitch:** Plants grow into the space you forbid them from using; by pruning and blocking cells you force living shapes to emerge from negative space.

Why it advances:
- unusually legible inverse verb;
- strong growth animation/GIF potential;
- discrete deterministic simulation;
- supports competition, boundary seeking and delayed consequences.

**Kill conditions:**
1. feels like cellular automata with obstacles;
2. growth rules cannot be predicted locally by players;
3. solving devolves into exhaustive search;
4. second species adds complexity without qualitatively new reasoning.

## T4 — Photocopier Garden
**Pitch:** Copy any rectangular patch of a living pattern; originals freeze for one generation while copies age, letting the player manufacture controlled phase differences.

Why it advances:
- copy/freeze/age consequence is clip-readable;
- rectangular selection gives strong input simplicity;
- overlapping age offsets can create deep state planning;
- procedural validation is plausible.

**Kill conditions:**
1. generic CA knowledge solves most content;
2. phase offsets become pure turn counting;
3. state readability collapses after overlapping copies;
4. satisfying goals require arbitrary target bitmaps rather than meaningful structures.

## T5 — Inventory Eclipse
**Pitch:** Tools physically disappear when covered by another inventory slot’s shadow; rearranging the pack phases capabilities in and out of the world.

Why it advances:
- inventory screen itself becomes the puzzle surface;
- extremely strong clip/screenshot communication;
- no physics/networking/large-world requirement;
- potential for exploration/puzzle hybrid without huge level count.

**Kill conditions:**
1. inventory packing dominates world interaction;
2. “cover unused tools” is a dominant heuristic;
3. occlusion rules feel arbitrary rather than physically obvious;
4. every challenge depends on bespoke tool exceptions.

## T6 — Consensus Machine
**Pitch:** Machines act only when simple agents vote; instead of programming agents, you control which facts each agent is allowed to see.

Why it advances:
- strong second-order strategic idea: ignorance can be useful;
- deterministic, solver-friendly discrete system;
- rule vocabulary can remain small while scenarios recombine;
- excellent adversarial potential around quorum/veto/visibility.

**Kill conditions:**
1. UI becomes truth-table bookkeeping;
2. maximizing information usually wins;
3. player cannot predict votes without opening panels repeatedly;
4. content demands many agent archetypes rather than recombination.

## T7 — Evaporation Map
**Pitch:** Paint a finite amount of water onto a miniature map; every evaporation step leaves salt walls behind, so today’s flow creates tomorrow’s terrain.

Why it advances:
- immediate visual transformation;
- temporal residue creates second-order planning;
- can use discrete tile flow, avoiding full fluid simulation;
- strong demo progression from one pour to chained basins.

**Kill conditions:**
1. discrete flow still appears arbitrary;
2. salt-wall accumulation makes later states unreadable;
3. high-ground-first becomes dominant;
4. content becomes ordinary pipe-routing with decorative water.

## T8 — Unreliable Ruler
**Pitch:** Every measurement changes the ruler’s scale for the next measurement; construct objects within tolerances by choosing what to measure, and in what order.

Why it advances:
- exceptionally original causal verb with tiny asset scope;
- deterministic and implementation-safe;
- potential for elegant physical bench presentation;
- measurement order creates stateful planning without large worlds.

**Kill conditions:**
1. gameplay reads as arithmetic homework;
2. optimal solution is always recalibrate/reference/reference/target;
3. scale changes require numeric UI rather than visual inference;
4. advanced depth needs many arbitrary formulas.

## T9 — Taxidermy of Motion
**Pitch:** Capture a single pose from a moving mechanism and mount that pose elsewhere as permanent static geometry.

Why it advances:
- strong trailer moment: freeze a wheel arm mid-swing, then use its captured geometry as a bridge/key/occluder;
- distinct from rewind/clones if capture creates a detached static artifact;
- compact authored arenas can recombine moving sources and placement targets.

**Kill conditions:**
1. players interpret it as ordinary time-freeze clone gameplay;
2. collision capture creates too many ambiguous edge cases;
3. extrema poses solve most problems;
4. level authoring burden exceeds systemic reuse.

## T10 — Moth Ledger
**Pitch:** Machines are governed by visible physical rule-clauses; guide moths to eat selected clauses, permanently simplifying or destabilizing the machine.

Why it advances:
- bizarre, legible, marketable verb;
- rule removal rather than rule addition creates clear irreversible tension;
- clauses can be iconographic and spatially placed;
- strong sequence dependence if machine motion alters moth routes.

**Kill conditions:**
1. clauses become textual programming;
2. deleting the strongest restriction first dominates;
3. moth navigation is filler between decisions;
4. many bespoke clause types are needed for depth.

## T11 — Counterweight Kitchen
**Pitch:** Cook on a hanging mobile: adding or removing ingredients shifts the whole kitchen, moving pans, flames, shelves and timers relative to one another.

Why it advances:
- instantly readable visual causality and comic charm;
- mass placement can produce spatial routing, not just balancing;
- kitchen theme gives natural timers/states without narrative burden.

**Kill conditions:**
1. solutions reduce to solving torque equations;
2. physics jitter makes precise planning unreliable;
3. cooking timers turn it into execution dexterity;
4. every recipe needs bespoke scripted behavior.

## T12 — Moth Ledger / alternate pressure check: Ink Debt
**Pitch:** Every mark drawn on one flipbook page borrows pigment from adjacent future pages; making one frame more explicit impoverishes nearby frames and changes the resulting animation.

Why it advances:
- strong visible conservation across time rather than a generic mana bar;
- drawing/erasing is direct and tactile;
- animation playback gives immediate “result clip” payoff;
- could generate content from motion constraints rather than bespoke art.

**Kill conditions:**
1. turns into simple pigment-budget allocation;
2. drawing skill matters more than reasoning;
3. accessibility requires too much freehand precision;
4. portfolio collision with conserved-resource logic becomes materially similar to #005 despite different state space.

Note: T12 is deliberately retained despite the portfolio-collision warning so Phase 2 can try to kill it early rather than silently rediscover the lane later.

# 8. Phase-2 tournament protocol
Phase 2 must not choose by score averaging alone. Every entrant gets the same destructive tests.

## Round A — 12 -> 6
For each entrant:
1. write one 20-second first-play scenario;
2. write one hour-3 scenario;
3. write one hour-8 scenario;
4. construct at least two microcases manually and solve them;
5. identify the simplest dominant heuristic and build a counterexample;
6. estimate minimum rule vocabulary and content production burden;
7. compare against named current/past analogues for derivative risk;
8. kill immediately if the core verb is not visible in motion or if the depth claim depends on unproven content quantity.

## Round B — 6 -> 3
For survivors:
- define minimal deterministic state model;
