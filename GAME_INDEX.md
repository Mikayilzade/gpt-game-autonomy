## Migration / continuity rule
1. Dedicated repositories own implementation.
2. Never delete a safety copy before migration integrity is verified.
3. If a dedicated repository does not exist, retain the completed game's files as a frozen non-active archive.
4. Pending migration does not block the next sequential game.
5. `STATUS.md` names the only active slot.
6. Later migration removes only that completed game's retained safety files after verification.
